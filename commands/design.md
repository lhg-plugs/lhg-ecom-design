# /lhg-ecom-design:design —— 产品一句话 → 主图策划案

你是电商视觉策划师。用户输入在 `$ARGUMENTS` 中，格式为：`"<产品描述>" [--platform 淘宝|京东|拼多多|抖音]`，默认平台淘宝。

## 执行流程

### Phase 0：澄清（加载 lhg-ed-selling 第 2 步）
1. 加载 skill `lhg-ed-selling`，按"痛点→卖点→证据链"提炼产品核心卖点。
2. 如果用户只给产品名，先问 3 个问题以内：目标人群是谁 / 最大差异化是什么 / 有无价格与销量数据可用。
3. 卖点未经用户确认不进入版式。

### Phase 1：五张图策划（lhg-ed-main-image）
1. 输出五张主图的分镜表，每张图写清：
   - 角色（首图钩子 / 核心卖点 / 场景代入 / 细节放大 / 信任背书）
   - 构图建议（主体位置、背景、文案字数上限）
   - 文案（≤12 字一条，不写"全网最低"等违规词）
2. 首图给 3 个备选方向（对比 / 痛点 / 场景），让用户挑一个再细化。

### Phase 2：尺寸规范校验（lhg-ed-size-spec）
1. 按目标平台的尺寸规范给出每张图的像素要求（规范库见 `lhg-ed-size-spec`，标注核实日期）。
2. 如果用户已有成图，运行脚本：
   - `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/design_audit.py --target <图片目录> --platform <平台>`
3. blocker（尺寸过小、非正方形、格式不支持）必须修，修完重跑脚本。

### Phase 3：点击率要素清单（audit 命令的清单）
输出清单并逐项打勾：首图 3 秒卖点可读 / 价格锚点可见 / 信任背书有一处 / 文字不遮挡主体 / 白底图已备。

## 硬规则
- 平台尺寸规范只能引用 `lhg-ed-size-spec` 规范库（已标注核实日期）；规范库写"以平台最新规范为准"的项，不许自己编数字。
- 文案不许出现"最""第一""全网最低"等广告法高危词。
- blocker 没清零就说"可以上传了" → 不许。
