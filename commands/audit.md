# /lhg-ecom-design:audit —— 点击率要素清单评审

对 `$ARGUMENTS` 描述的商品图做一次人工评审（脚本抓不到的部分）。先跑 `/lhg-ecom-design:size-check` 做机器体检，再过下面清单。

## 12 项点击率清单

**首图（前 3 秒）**
1. [ ] 3 米外能看清卖的是什么（主体占比 ≥50%，不被文字遮挡）
2. [ ] 核心卖点 3 秒可读（≤12 字，无"最/第一/全网最低"）
3. [ ] 与同类目 TOP 图有视觉差异（颜色/构图/角度至少一处不同）

**价格与促销**
4. [ ] 价格锚点可见（原价划线或"券后价"二选一，不许双标价误导）
5. [ ] 促销信息不喧宾夺主（文字区 ≤30% 画面，主体不被挡）

**信任背书**
6. [ ] 至少一处信任元素（销量/评价截图/质检报告/品牌授权，真实可查）
7. [ ] 白底图已备一张（淘宝第五张主图位，用于猜你喜欢流量）

**合规与体验**
8. [ ] 无广告法高危词（最/第一/顶级/全网最低/国家级）
9. [ ] 无盗图嫌疑（图与自家实物一致，不确定的换实拍）
10. [ ] 文件名规范（英文/拼音+序号，无中文无空格）

**详情页（如有）**
11. [ ] 宽度 750px 上下，手机端不横向滚动
12. [ ] 首屏解决"这是什么+为什么买我"，不堆参数表

## 输出
- 逐项 ✓/✗，✗ 项给一句话修改建议
- 结论只能是"通过"或"不通过"；不通过列出必须改的前 3 项
- 结论存为 `docs/ecom-design-audit-YYYYMMDD.md`（如用户同意）
